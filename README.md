# ESO-Addon-FasterCurrencyDeposits
Tired of manually clicking through multiple menus and typing in amounts just to empty your pockets at the bank? **Faster Currency Deposits** is an Elder Scrolls Online addon that allows you to quickly deposit all your selected currencies into your personal bank with either a simple button or automatically upon opening the deposit window. Supporting Gold, Tel Var, Alliance Points, and Writ Vouchers, you should spend less time talking to the banker and more time grinding. 


## ✨ Features

* **One-Click Deposits:** Adds a ESO themed "Deposit Currencies" button directly to the bank deposits UI.
* **Optional Auto-Deposit:** Toggle on `Auto Deposit` in the settings menu to automatically deposit your currency the moment you open the deposits screen.
* **Full Currency Coverage:** Automatically detects and deposits:
  * 💰 Gold
  * 🟣 Tel Var Stones
  * ⚔️ Alliance Points
  * 📜 Writ Vouchers
* **Granular Control:** Choose exactly which currencies to automate and which ones to keep on your character.
* **Chat Summary:** Prints a deposit summary to your chat detailing exactly how much of each currency was safely locked away.
* **Reserve Thresholds:** Specify the minimum amount of each currency you want to keep in your inventory.

## 🛠️ Installation & Dependencies
FasterCurrencyDeposits can be installed manually from [Github][3], [ESOUI][1] or the [Minion Addon Manager][2].

### Required Libraries
To access the configuration panel, you must install the following dependency:
* `LibAddonMenu-2.0` (Available via [Minion][2] or [ESOUI][1])

### Installing manually
To install manually,

1. Navigate to [Releases][3]
2. Select the latest release and hit download zip
3. Extract the downloaded `FasterCurrencyDeposits.zip` folder
4. Open the unzipped folder and copy the FasterCurrencyDeposits folder
5. Paste the copied FasterCurrencyDeposits folder into the ESO AddOns folder

**NOTE:** The ESO Addon folder is usually found at `Documents/Elder Scrolls Online/live/AddOns/`

### Installing from ESOUI
To install from ESOUI,

1. Navigate to the [FasterCurrencyDeposits][4] page on ESOUI
2. Press the big "Download" button
3. Extract the downloaded `FasterCurrencyDeposits.zip` folder
4. Open the unzipped folder and copy the FasterCurrencyDeposits folder
5. Paste the copied FasterCurrencyDeposits folder into the ESO AddOns folder

**NOTE:** The ESO Addon folder is usually found at `Documents/Elder Scrolls Online/live/AddOns/`

### Installing from Minion
To install from Minion,

1. Download [Minion][2]
2. Search for 'FasterCurrencyDeposits'
3. Verify the author is `revelmonger`
4. Hit the install button
